# Futaba 設計（v1）

アプリ名: **Futaba**（双葉。アイデアの種が芽を出したばかりの状態。2026-11-26 決定）
画面上の表記は「Futaba」。アプリ名の位置（ヘッダー・ドロワー・ウィジェット・ランチャー）以外の「アイデア」という一般語はそのまま。

画面デザインの正本: claude.ai Design アーティファクト「Futaba UX・画面デザイン」
https://claude.ai/artifact/XNVpYyrRaFq4GFHVAdE2gy （画面01〜14・画面遷移図）
このファイルはその文章版＋技術判断の記録。食い違ったら画面はアーティファクト、技術はこのファイルを優先。

## コンセプト

「書くまで0秒。整理はあとで、しなくてもいい。」
自分しか見ない垂れ流しのアイデア帳。保存場所・タイトルを決める手間を全部なくす。
Googleアカウントは端末間で同じものを見るためだけに使う。

## 原則

1. 起動＝入力。開いた時点で入力欄にフォーカス、キーボード表示済み
2. フォルダではなくラベル。1件に複数。本文の `#ラベル` でも後からでも付く
3. 時系列で流すだけ。新しい順・日付区切り。並び替え設定は持たない
4. ログインは後から。初回は登録なしで書ける。同期は設定からオン
5. 確認ダイアログを出さない。保存は自動、削除は即時＋「元に戻す」

## 主要フロー

**A. 書く**
1. 起動 → 入力欄にフォーカス済み
2. 書くほど入力欄が上に広がる（最大8行、超えたら欄内スクロール）。Enterは改行、保存は送信ボタンだけ
3. `#` を打つと既存ラベルを候補表示（よく使う順）
4. 送信で一覧の先頭に追加、入力欄は空になりフォーカスを保つ（連続して書ける）
5. 送信せずに閉じても下書きは残る（端末ローカルに保存）

**B. 見返す**: スクロール／検索／ドロワーでラベル選択 → タップで詳細、そのまま編集・自動保存

**C. 分類する（Gmail式）**
- 詳細のラベルボタン、または長押し→複数選択→ラベル
- ラベル別一覧（11）で書いたメモには自動でそのラベルが付く
- 「ラベルなし」で未分類だけを見てまとめて整理

**D. 同期を始める**: 設定 →「Googleで同期」→ 端末のメモをそのアカウントに引き継ぐ → 別端末で同じアカウントにログインすると同じ一覧

## 技術選定（2026-11-26 確定）

- **Android**: Kotlin / Jetpack Compose + Material 3、ViewModel + StateFlow、Hilt、Navigation 3、単一モジュールで機能別パッケージ（詳細は実装計画の Tech Stack）
- **検査**: GitHub Actions は使わない（費用）。lefthook の pre-push で `pnpm check`（ktlint・detekt・Android Lint・単体テスト・oxlint・tsc・ルールテスト）を走らせて CI の代わりにする
- **バックエンド**: Firebase（Spark 無料プラン、課金登録なし）。自前サーバなし
  - 選定理由: 個人利用で0円（Firestore 読み5万/日・書き2万/日・1GiB）、Kotlin と JS の両方に公式SDK、書くコードが最少
  - 不採用: Google Drive appDataFolder（同期・競合を自作、OAuthテスト公開だとトークン7日失効）、Supabase 無料（1週間無操作で停止）、Cloudflare Workers+D1（認証・API自作）
- **ブラウザ拡張**: Chrome Manifest V3 + WXT + TypeScript + Firebase JS SDK（lint は `@caffelatte23/oxc-config`）

### 認証

- 初回は Firebase Auth の匿名ログイン
- 同期オン時に Credential Manager で Google の ID トークンを取得 → `GoogleAuthProvider.getCredential` → `linkWithCredential`。uid が変わらないのでデータ移行不要
- そのGoogleアカウントが既に別uidに紐付いている場合（`FirebaseAuthUserCollisionException`、2台目の端末など）: そのcredentialで `signInWithCredential` し、匿名uidのメモを新uidへバッチコピーしてから匿名側を削除（「端末のメモを引き継ぐ」）
- 注意: 匿名ログインは初回だけネットワークが要る。オフライン初回起動では uid が無いので、入力は下書きとして端末に保持し、ログイン成功後に保存する

### 同期・保存（Firestore オフラインキャッシュ方式）

- 端末内DB（Room）は持たない。Firestore SDK の永続キャッシュ（Android は既定で有効）が手元の正本
- 一覧は `users/{uid}/notes` を `orderBy("createdAt", DESC)` で `snapshots()` 購読し Flow で表示
- ラベル絞り込み・ピン留め・「ラベルなし」・全文検索はメモリ上の全件をフィルタ（ponytail: 数千件規模まで。重くなったら `whereArrayContains("labelIds", id)` クエリへ）
- 書き込みは await しない。キャッシュに即反映し、送信・オフライン時の再送は SDK 任せ
- 競合は最後の書き込みが勝つ（SDK既定）
- 削除は `deletedAt` を立てるソフト削除。一覧から即消え、スナックバー「元に戻す」（5秒）で `deletedAt` を消す。確認ダイアログなし
- 設定「最近削除したもの」で復元できる。`deletedAt` から30日経ったものは起動時に端末側で本削除（Cloud Functions は使わない＝Spark で動く）
- 読み取り課金の目安: リスナー再接続が30分以上空くと全件分の読み取りになる。1000件×50回起動/日でも無料枠内
- 下書き（未送信の入力）は DataStore に保存

### データ

```
users/{uid}/notes/{id}
  text: string
  labelIds: string[]
  pinned: bool
  createdAt: timestamp
  updatedAt: timestamp
  deletedAt: timestamp | null   // ゴミ箱。30日で本削除

users/{uid}/labels/{id}
  name: string
  color: string
  order: number
```

- 本文中の `#ラベル` は保存時に labelIds へ変換（無ければラベルを作成。IDはクライアント生成）
- ラベルの改名・削除で本文は書き換えない。ラベル削除時はそのIDを各メモの labelIds から外す（メモは消さない）
- `#` の判定: `#` または `＃` の直前が文字・数字・`/`・`&` でなく、直後に文字・数字・`_`・`-` が1つ以上続くもの。大文字小文字を区別せず重複除去。URLの `/#anchor` や `色#123` はラベルにしない。テストケースは `spec/hashtags.json` を Android と拡張で共有

### 設定画面（06）の補足

- 同期行は「最終同期 / 今すぐ同期」ではなく SDK の未送信状態を表示（「すべて送信済み」/「未送信 n件」）。今すぐ同期ボタンは作らない（リスナーで常時同期のため）
- 書き出しは Markdown（1メモ1ブロック、日付見出し、ラベルは末尾に `#ラベル`）を SAF で保存
- 「起動時にキーボードを開く」トグル（既定オン）、テーマ（端末に合わせる/ライト/ダーク）は DataStore

### セキュリティルール

```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /users/{uid}/{doc=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

### ブラウザ拡張（v1の範囲）

- ポップアップで書く（入力欄のみ、送信で1件追加）
- 右クリックメニュー「Futabaに追加」で選択中テキストとページURLを1件追加。ページ上で選択せずに実行するとページURLを追加する。未ログイン時は入力を保留し、ログイン後にポップアップの入力欄へ表示する
- ログイン: `chrome.identity.launchWebAuthFlow` で Google ID トークン → `signInWithCredential`。Androidでリンク済みのGoogleアカウントなら同じuid
- 一覧表示は v1 では作らない

## v1でやらないこと

フォルダ／ノートブック・リッチテキスト・画像添付・共有や共同編集・リマインダー・自動分類・拡張での一覧表示。必要になったら足す。
